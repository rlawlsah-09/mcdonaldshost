# 맥도날드 키오스크 연습 서비스 (Digital Kiosk Tutor)

> **"함께라서 쉬운 디지털 - 맥도날드 키오스크 편" 기반 디지털 약자 및 어르신 맞춤형 키오스크 실습 웹 애플리케이션**

---

## 📌 주요 개선 및 해결 사항 (최신 업데이트)

1. **시작 시 [모드 선택] 창 즉시 호출**
   - 웹 애플리케이션을 처음 열거나 상단 [🔄 다시 시작] 버튼을 누르면, **[미션 연습 모드]**와 **[자유 주문 모드]**를 선택할 수 있는 웰컴 모달 창이 화면 전면에 가장 먼저 뜹니다.

2. **실제 매장 키오스크와 동일한 시작 화면(대기 화면) 표시**
   - 모드를 선택하면 실제 맥도날드 키오스크와 동일한 화면이 뜹니다.
   - 상단 프로모션 포스터(페퍼로니 피자 버거 배너 및 네온 로고), 중단 공지사항, 하단 **포인트 적립 QR 및 우측 [주문하기 (Start Order)]** 버튼이 배치된 실제 매장 대기 화면으로 시작합니다.

3. **[주문하기] 터치 시 [식사 장소 선택] 화면 전환**
   - 우측 하단 [주문하기] 버튼이나 화면을 터치하면 포장인지 매장 식사인지 선택하는 식사 장소 선택 화면으로 이동합니다.
   - 좌우 2열 대형 카드(왼쪽: 🍽️ 매장에서 식사 / 오른쪽: 🛍️ 테이크 아웃)로 명확히 안내됩니다.

4. **미션 연습 모드: [포장 (테이크 아웃)] 실습**
   - 미션 모드에서는 **포장(테이크 아웃)** 연습으로 진행됩니다.
   - 상단 가이드 및 인라인 유도등 배지가 오른쪽 **[테이크 아웃 (포장)]** 카드를 가리킵니다.
   - 실수로 왼쪽 [매장에서 식사]를 누르면 *"⚠️ 이번 미션 목표는 '테이크 아웃 (포장)'입니다! 오른쪽 [테이크 아웃 (포장)]을 선택해 주세요."* 안내와 경고음이 발생하여 올바른 선택을 유도합니다.

5. **추천 메뉴에서 빅맥 제거 (직접 버거 탭 탐색 실습)**
   - 실제 매장처럼 3단계에서 왼쪽 카테고리의 **[버거 & 세트]** 탭을 직접 눌러 빅맥을 찾아 선택하도록 유도합니다.

6. **빅맥 외 다른 메뉴 선택 완전 차단 (오주문 방지 가드)**
   - 미션 진행 중 빅맥이 아닌 다른 메뉴를 누르면 모달이 열리지 않고 하단에 즉시 경고가 출력됩니다.

7. **담기 과정(모달) 및 장바구니 실시간 단계별 안내**
   - 세트/사이즈/음료 선택 팝업 모달 상단에도 각각 5단계, 6단계, 7단계 미션 전용 안내 바를 배치하여 직관적으로 따라갈 수 있습니다.

8. **하드웨어 꽂힌 카드 직접 클릭 수거**
   - 결제 완료 시 화면의 버튼이 아닌, 기기 하단에 **실제 꽂혀있는 카드를 직접 손으로 터치**해야 카드가 쏙 뽑히며 영수증이 출력됩니다.

9. **상태 기반(State-Based) 미션 자동 동기화 엔진**
   - 화면 전환, 모달 상태, 장바구니 내용, 카드 상태를 실시간 종합하여 1~13단계를 정확히 산출합니다.

10. **원터치 다시 시작 및 모드 재선택**
    - 상단 [🔄 다시 시작] 버튼이나 결제 완료 후 [처음으로 돌아가기] 버튼을 누르면 언제든 모든 상태가 초기화되고 **모드 선택 화면**으로 복귀합니다.

---

## 🎯 미션 시나리오 13단계 흐름 안내 (빅맥 세트 포장 주문)

1. **주문 시작**: 화면 우측 하단 [주문하기 (Start Order)] 터치
2. **식사 장소**: 오른쪽 [테이크 아웃 (포장)] 큰 카드 터치
3. **카테고리 이동**: 왼쪽 [버거 & 세트] 탭 터치
4. **버거 선택**: 화면에서 [빅맥] 메뉴 카드 터치
5. **세트 주문**: 큰 카드 중 [세트로 주문] 터치
6. **사이즈 선택**: [M사이즈 (기본)] 터치
7. **음료 선택**: 음료 확인 후 [이 음료로 담기] 터치
8. **장바구니 확인**: 맨 아래 [주문내역 확인 후 결제하기] 터치
9. **주문 확인**: 내역 확인 후 [주문 완료 (결제)] 터치
10. **결제수단 선택**: [신용 / 체크카드] 터치
11. **카드 투입**: 기기 아래 [IC CARD 삽입구] 터치
12. **카드 뽑기**: 꽂혀있는 카드를 직접 터치해 쏙 뽑기
13. **주문 완료!**: 영수증과 번호표 확인 후 [처음으로 돌아가기] 터치

## 🚀 실행 방법

- **더블클릭 실행**: `run.bat` 파일을 더블클릭하거나 `index.html`을 크롬/엣지 브라우저에서 바로 열어 사용합니다.
- 외부 라이브러리나 서버 구동이 필요 없는 순수 HTML5 / CSS3 / Vanilla JavaScript 웹 애플리케이션입니다.
